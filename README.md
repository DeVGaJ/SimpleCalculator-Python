# SimpleCalculator-Python
A simple calculator

Python Calculator (Tkinter)

A simple calculator with a GUI that supports:

· Addition, subtraction, multiplication, division
· Clear entry (C)
· Decimal point
· Evaluate expression using eval() (safe for this demo)

Dependencies & How to Run

· Python 3 (with Tkinter – usually included by default)
· No extra packages needed.
· Run:
  ```bash
  cd python
  python calculator.py
  ```
